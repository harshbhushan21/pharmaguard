# Contributing to PharmaGuard

Thank you for your interest in contributing to PharmaGuard!

## Development Setup

1. Fork the repository
2. Clone your fork
3. Set up backend and frontend as described in README.md
4. Create a new branch for your feature: `git checkout -b feature/your-feature-name`

## Code Style

- Backend: Follow PEP 8 style guide
- Frontend: Use ESLint configuration
- Write tests for new features
- Update documentation as needed

## Testing

Run tests before submitting:
```bash
cd backend
pytest tests/
```

## Submitting Changes

1. Commit your changes with clear messages
2. Push to your fork
3. Create a pull request with a detailed description

## Questions?

Feel free to open an issue for questions or discussions.
